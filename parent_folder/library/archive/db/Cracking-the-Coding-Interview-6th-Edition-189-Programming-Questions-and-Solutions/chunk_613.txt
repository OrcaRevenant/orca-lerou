One major inefficiency in this algorithm is finding all strings that are one edit away. Right now, we're finding
the strings that are one edit away and then eliminating the invalid ones.
Ideally, we want to only go to the ones that are valid.
Optimized Solution
To travel to only valid words, we dearly need a way of going from each word to a list of all the valid related
words.
What makes two words "related" (one edit away)?They are one edit away if all but one character is the same.
For example, b a l l and b i l l are one edit away, because they are both in the form b _ l l . Therefore, one
approach is to group all words that look like b _ l l together.
We can do this for the whole dictionary by creating a mapping from a "wildcard word" (like b _ l l ) to a list
of all words in this form. For example, for a very small dictionary tike { a l l , i l l , a i l , ape, a l e } the
mapping might look like this:
