Notice in the output above that the OS/Arch: for the Server component is
showing as linux/amd64. This is because the server portion of the Docker
Engine (a.k.a. the “daemon”) is running inside of the Linux VM we mentioned
earlier. The Client component is a native Mac application and runs directly on
the Mac OS Darwin kernel (OS/Arch: darwin/amd64).
Also note that the system is running the experimental version (Experimental:
true) of Docker. This is because the system is running the edge version which
comes with experimental features turned on.
