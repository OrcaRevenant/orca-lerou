Docker Trusted Registry (DTR), which is an on-premises Docker registry
included as part of Docker Enterprise Edition, provides the same capabilities and
gives you control over how and when image scans are performed. For example,
DTR lets you decide if images should be automatically scanned as soon as they
are pushed, or if scans should only be triggered manually. It also allows you to
manually upload CVE database updates - this is ideal for situations where your
DTR infrastructure is air-gapped from the internet and cannot automatically sync
updates.
Signing and verifying images with Docker Content Trust
Docker Content Trust (DCT) makes it simple and easy to verify the integrity and
the publisher of images that you download. This is especially important when
pulling images over untrusted networks such as the internet.
