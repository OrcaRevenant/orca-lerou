Docker uses seccomp, in filter mode, to limit the syscalls a container can make
to the host’s kernel.
As per the Docker security philosophy, all new containers get a default seccomp
profile configured with sensible defaults. This is intended to provide moderate
security without impacting application compatibility.
As always, you can customize seccomp profiles and you can pass a flag to
Docker so that containers can be started without a seccomp profile.
Final thoughts on the Linux security technologies
Docker supports most of the important Linux security technologies and ships
with sensible defaults that add security but aren’t too restrictive.
