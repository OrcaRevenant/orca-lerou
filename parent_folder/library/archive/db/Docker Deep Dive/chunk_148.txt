As shown above, the container on node1 can ping the container on node2 using
the overlay network.
You can also trace the route of the ping command from within the container.
This will report only a single hop, proving that the containers are communicating
directly over the overlay network - blissfully unaware of any underlay networks
that are being traversed.
For the traceroute to work on the Linux example you will need to install the
traceroute package.
