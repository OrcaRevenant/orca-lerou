Note: The docker history command shows the build history of an image
and is not a strict list of layers in the image. For example, some Dockerfile
instructions used to build an image do not result in layers being created.
These include; “MAINTAINER”, “ENV”, “EXPOSE” and
“ENTRYPOINT”. Instead of these creating new layers, they add metadata
to the image.
All Docker images start with a base layer, and as changes are made and new
content is added, new layers are added on top.
As an over-simplified example, you might create a new image based off Ubuntu
Linux 16.04. This would be your image’s first layer. If you later add the Python
package, this would be added as a second layer on top of the base layer. If you
